# zp-maps

Карта дорог для ZeroPilot (форк openpilot на OnePlus 3T). В карте все дороги Ростовской области, Краснодарского края и Адыгеи и трассы России: motorway, trunk, их съезды и primary с федеральным номером. Без GPS ZeroPilot определяет положение машины по этой карте.

## Сборка

- Workflow `map` (`.github/workflows/map.yml`) запускается в ночь на понедельник, в 01:00 по Москве. Вручную: Actions, map, Run workflow, в том числе из приложения GitHub.
- `build.sh` скачивает выгрузку России с Geofabrik и проверяет её md5. Затем вырезает регионы по их границам (отношения OSM из `regions.json`), добавляет трассы России и собирает карту сборщиком `tools/zp/osm_highways.py`.
- Код в `openpilot/` и `tools/zp/` вместе с тестами скопирован из закрытого репозитория ZeroPilot скриптом `tools/zp/zp_maps_sync.sh` того репозитория. Изменения вносятся там, сюда переносится копия.
- Проверка на Маке: `PYTHON=<python с osmium и numpy> ./build.sh <папка> <russia.osm.pbf>`, затем `PYTHONPATH=. python3 release.py <папка> out`.

## Проверки

Перед сборкой выполняются тесты сборщика и формата карты (`openpilot/selfdrive/zeropilot/tests/test_highways.py`). `release.py` перед публикацией:

- Сравнивает с `stats.json` (числа прошлой публикации) число дорог OSM (way) классов карты в каждом регионе, число трасс России и число рёбер карты. Если какое-то число изменилось больше чем на 5 %, карта не публикуется: сборка завершается с ошибкой, и GitHub присылает владельцу письмо. Чтобы опубликовать такую карту, запустите workflow вручную с отметкой force.
- Восстанавливает карту из публикуемой части тем же кодом, что работает на телефоне. Результат должен совпасть с собранной картой байт в байт.
- Открывает карту так же, как ZeroPilot.

## Релиз

Тег релиза: дата данных OSM, например `2026-10-04`. Файлы:

- `south.bin.xz`: карта без разделов `along`, `gal`, `bear`, `edge_len`, `edge_off` (их телефон считает сам), около 13 МБ.
- `map.json`: версия формата, время данных OSM, тег и файл релиза, md5 карты без этих разделов, числа проверки.

Если релиз с таким тегом уже есть, сборка ничего не публикует. После публикации сборка коммитит `stats.json`. Эти коммиты заодно не дают GitHub отключить расписание: в репозитории без коммитов он отключает его через 60 дней.

## Телефон

Процесс `mapupdated` ZeroPilot работает, пока машина стоит. Раз в 6 часов он читает `releases/latest/download/map.json`. Кнопка "Обновить" в настройках скачивает `south.bin.xz`, проверяет md5, считает недостающие разделы и заменяет карту. Новая карта работает со следующей поездки. Прежняя карта сохраняется, кнопка "Вернуть" ставит её обратно.
