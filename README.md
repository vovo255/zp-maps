# zp-maps

Карта дорог для ZeroPilot (форк openpilot на OnePlus 3T). В карте все дороги России, по которым ездят машины: классы OSM от motorway до residential и living_street. Без GPS ZeroPilot определяет положение машины по этой карте.

## Сборка

- Workflow `map` (`.github/workflows/map.yml`) запускается в ночь на понедельник, в 01:00 по Москве. Вручную: Actions, map, Run workflow, в том числе из приложения GitHub.
- `build.sh` скачивает выгрузку России с Geofabrik, проверяет её md5 и собирает карту сборщиком `tools/zp/osm_highways.py` с ключом `--all-streets`. На Маке сборка занимает около 1,5 минуты и до 9 ГБ памяти.
- При ручном запуске без отметки publish workflow только собирает и проверяет карту, релиз не создаётся.
- Код в `openpilot/` и `tools/zp/` вместе с тестами скопирован из закрытого репозитория ZeroPilot скриптом `tools/zp/zp_maps_sync.sh` того репозитория. Изменения вносятся там, сюда переносится копия.
- Проверка на Маке: `PYTHON=<python с osmium и numpy> ./build.sh <папка> <russia.osm.pbf>`, затем `PYTHONPATH=. python3 release.py <папка> out`.

## Проверки

Перед сборкой выполняются тесты сборщика и формата карты (`openpilot/selfdrive/zeropilot/tests/test_highways.py`). `release.py` перед публикацией:

- Сравнивает с `stats.json` (числа прошлой публикации) число рёбер карты по группам классов: motorway, trunk, primary и их съезды; secondary; tertiary; unclassified; residential и living_street. В каждой группе больше 280 тысяч рёбер, поэтому изменение больше 5 % за неделю означает неполную выгрузку или ошибку сборщика. В этом случае карта не публикуется: сборка завершается с ошибкой, и GitHub присылает владельцу письмо. Чтобы опубликовать такую карту, запустите workflow вручную с отметкой force. Без `stats.json` сравнение не выполняется.
- Восстанавливает карту из публикуемой части тем же кодом, что работает на телефоне. Результат должен совпасть с собранной картой байт в байт.
- Открывает карту так же, как ZeroPilot.

## Релиз

Тег релиза: дата данных OSM, например `2026-10-04`. Файлы:

- `russia.bin.xz`: карта без разделов `along`, `gal`, `bear`, `edge_len`, `edge_off` (их телефон считает сам), около 150 МБ. С этими разделами карта занимает на телефоне около 1,3 ГБ.
- `map.json`: версия формата, время данных OSM, тег и файл релиза, md5 карты без этих разделов, числа проверки.

Если релиз с таким тегом уже есть, сборка ничего не публикует. После публикации сборка коммитит `stats.json`. Эти коммиты заодно не дают GitHub отключить расписание: в репозитории без коммитов он отключает его через 60 дней.

## Телефон

Процесс `mapupdated` ZeroPilot работает, пока машина стоит. Раз в 6 часов он читает `releases/latest/download/map.json`. Кнопка "Обновить" в настройках скачивает файл из `map.json`, проверяет md5, считает недостающие разделы и заменяет карту. Новая карта работает со следующей поездки. Прежняя карта сохраняется, кнопка "Вернуть" ставит её обратно.
